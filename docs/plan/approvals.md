# 待批准与待决定事项

只有项目负责人 hanyu 本人的批准才算数。代理、审查人的意见不算批准。凡涉及停服务、删数据、动线上库，执行前都要先把具体命令列出来过目。

## 需要 hanyu 定的口径

1. **门① 分母**：A＝全部格式清楚的报单；B＝只算纯标准行（D144 快通道）。
2. **新客户首报**：要不要从门① 分母里拿出来单独报数。
3. **D151–D154** 是否追加进决策文件；R17 新增的括号非名字小词表（`BRACKET_NOT_NAME`）能不能用、要不要挪进 `config/`。
4. **自然句报单**（「我今天两笔：……」这一类）算快通道还是归模型路径；复合句是不是全部整句先问（见 R17 移交第 4、6 项）。
5. **LICENSE**：本仓库用什么许可证。
6. **爱美云取证材料**能否公开（目前没有放进本仓库）。
